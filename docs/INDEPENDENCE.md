# Independent implementation

This repository began as an empty Git repository on 2026-08-16. Its source,
tests, documentation, evaluation scripts, and commit history were written anew
for this project.

The implementation is based on public interfaces:

- DeepSeek Harness package APIs and profile/bundle documentation;
- OpenAI Codex App Server documentation;
- schemas generated locally by Codex CLI `0.147.0`;
- behavior observed through new scripted and live tests.

It does not retain another plugin's source files, tests, documentation, visual
assets, Git objects, author metadata, or commit ancestry. Public projects are
credited as research references in [RESEARCH.md](RESEARCH.md), not as upstream
code bases.

This statement describes project provenance; it is not a legal opinion or a
formal clean-room certification.
