## Direct Codex comparison

Both paths used `gpt-5.6-terra` and the same workspace. Times are single-run
wall-clock smoke measurements, not a benchmark.

| Scenario | DSH + plugin | Direct `codex exec` | Functional result |
| --- | ---: | ---: | --- |
| Exact answer | 5.785s | 6.37s | both exact |
| Read root package name | 11.703s | 11.24s | both `@deepseek-ai/dsh-root` |

The DSH path used DSH's `read` tool and durable agent loop. Direct Codex used
its native command execution. Prompt context, cache state, and tool surfaces
differ, so the timing delta should not be generalized. The useful conclusion
is functional parity with modest adapter overhead in this sample.
